# ShopSphere

A full-stack e-commerce project with a Next.js frontend and an Express + TypeScript backend.

## Project structure

- `frontend/` - Next.js web app
- `backend/` - Express API server

## Run frontend

```bash
cd frontend
npm install
npm run dev
```

## Run backend

```bash
cd backend
npm install
npm run dev
```

## Production build

```bash
cd frontend
npm run build

cd ../backend
npm run build
```

## GitHub

Create a GitHub repository and push the project from the root folder:

```bash
git init
git branch -M main
git remote add origin <your-github-repo-url>
git add .
git commit -m "Initial commit"
git push -u origin main
```
